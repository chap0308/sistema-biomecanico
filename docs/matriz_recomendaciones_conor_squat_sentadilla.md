# Matriz de recomendaciones Conor Harris × Squat University para la sentadilla

## 1. Propósito

Este documento define la capa de recomendaciones que puede acompañar las cuatro variables observables del sistema:

- inclinación lateral del tronco;
- desplazamiento lateral de pelvis;
- valgo dinámico visible o desviación medial proyectada;
- diferencia bilateral de alineación de rodillas.

Las recomendaciones no modifican la clasificación ni sus umbrales. Funcionan después del resultado:

```text
observable 2D
  -> combinación y fase
  -> hipótesis educativa
  -> prueba confirmatoria sugerida
  -> opción de bajo riesgo si la prueba coincide
  -> retest de la prueba y de la sentadilla
```

## 2. Reglas obligatorias de seguridad y evidencia

1. No diagnosticar un patrón PRI, una lesión o una causa anatómica desde el video.
2. No afirmar que un músculo está débil, tenso o inhibido solo por apariencia.
3. No recomendar un ejercicio específico si falta el test que diferencia las rutas posibles.
4. No interpretar una diferencia bilateral derivada como evidencia independiente de las dos rodillas.
5. No llamar valgo a una apertura lateral.
6. Atribuir claramente:
   - “Dentro del modelo de Harris…”;
   - “Squat University propone comprobar…”;
   - “El sistema observó…”.
7. Toda intervención debe incluir retest inmediato y advertir que una mejora puntual no demuestra reposicionamiento estructural.
8. Dolor agudo, trauma, inflamación importante, bloqueo, incapacidad de cargar peso, síntomas neurológicos, debilidad progresiva o dolor persistente requieren evaluación profesional.

## 3. Datos que pueden participar

### Datos automáticos

- estado global por variable;
- fase o fases de aparición;
- intervalos;
- dirección por episodio;
- estado en máxima profundidad;
- valor absoluto y delta desde baseline;
- rodilla izquierda, derecha y diferencia;
- duración/persistencia;
- calidad de pose.
- profundidad vertical normalizada y progreso relativo dentro del descenso, solo como contexto;
- consistencia entre repeticiones del mismo video, cuando existan dos o más.

### Datos que el sistema no debe asumir

- estabilidad del trípode del pie;
- colapso real del arco;
- dolor o localización del dolor;
- rotación tibial tridimensional;
- rotación interna o externa real de cadera;
- anatomía de acetábulo/fémur;
- movilidad de tobillo;
- fuerza o control neuromuscular;
- flexión anatómica de cadera en grados desde una vista frontal.

Estos elementos deben preguntarse o medirse con tests adicionales.

### Consistencia entre repeticiones

Cuando un video contenga varias repeticiones, la consistencia puede modificar la prioridad y confianza de una recomendación, pero nunca las clasificaciones independientes:

- misma combinación, misma dirección y exposición comparable: conservar la ruta de tests y aumentar solo la confianza descriptiva;
- presente en algunas repeticiones: mostrar `n de N` y describir comportamiento variable;
- direcciones opuestas: bloquear recomendaciones lateralizadas;
- compensaciones diferentes: no fusionar varias rutas correctivas; priorizar repetición estandarizada y tests diferenciales;
- profundidades diferentes: tratar la profundidad como exposición, no como causa ni como resultado de compensación;
- una sola repetición: aplicar la matriz normalmente, sin inferir consistencia.

Una síntesis comparativa nunca diagnostica una limitación de movilidad. Su función es evitar que una recomendación general oculte variabilidad de técnica, profundidad, velocidad, aprendizaje, fatiga o calidad de medición.

## 4. Niveles de recomendación

| Nivel | Salida permitida |
| --- | --- |
| 1. Descripción | Explicar qué se observó, cuándo y en qué lado. |
| 2. Verificación | Sugerir uno o dos tests que diferencien hipótesis. |
| 3. Opción práctica | Mostrar una regresión o drill de bajo riesgo solo si el test coincide y no hay dolor. |
| 4. Derivación | Recomendar evaluación profesional ante dolor, bloqueo, síntomas neurológicos o resultado no explicable. |

La vista de usuario debe empezar en nivel 1 y 2. El nivel 3 puede aparecer como “opción para probar y retestear”, nunca como tratamiento garantizado.

## 5. Matriz principal de combinaciones

### R1. Movimiento medial pequeño solo durante el ascenso

**Disparador**

- valgo proyectado aparece únicamente en ascenso;
- duración breve;
- no aparece en máxima profundidad;
- sin información de dolor ni pie.

**Lectura**

Squat University señala que una pequeña entrada de la rodilla durante el ascenso puede encontrarse dentro de un rango controlado si el pie permanece estable. Harris también diferencia IR genuina de un colapso compensatorio: la rodilla puede ir algo hacia dentro sin perder trípode.

**Texto de usuario**

> Se observó un movimiento medial breve durante el ascenso. Por sí solo no demuestra un colapso problemático; conviene comprobar si el pie mantuvo apoyo estable y si hubo dolor o pérdida de control.

**Verificación**

- revisar video frontal/posterior del pie;
- comprobar talón, base del dedo gordo y quinto metatarsiano;
- preguntar por dolor;
- comparar con tempo squat o single-leg squat si corresponde.

**No hacer automáticamente**

- no ordenar “rodillas afuera”;
- no recomendar clamshell por supuesta debilidad glútea.

**Fuentes**

- Squat University: `2PBkXKBIOhM`, `subgrupo-knee-valgus-knee-cave`;
- Conor Harris: `DMgO4EX81vs`, `NbWD_uIoBMU`, `familia-rodilla-pie-tibia-knee-cave`.

### R2. Movimiento medial durante el descenso o sostenido hasta el fondo

**Disparador**

- valgo proyectado aparece durante descenso;
- o permanece en máxima profundidad;
- especialmente si es unilateral o coincide con pelvis/tronco.

**Lectura**

Es una señal más útil para pedir tests, pero no identifica la causa. Las rutas principales son pie/tibia, tobillo, movilidad de cadera, estabilidad lateral y estrategia de carga.

**Verificación en orden**

1. estabilidad del pie/trípode y calzado;
2. knee-to-wall/dorsiflexión;
3. rotación tibial con pie estable;
4. FABER/ER e IR de cadera;
5. control unilateral con split squat o single-leg squat.

**Opciones si el hallazgo coincide**

- pie inestable: tempo squat, referencia bajo hallux o lateral foot, banda alrededor de tobillos;
- tobillo limitado: movilización de dorsiflexión y retest;
- movilidad de cadera limitada: movilidad específica y luego estabilidad/integración;
- control lateral limitado: assisted hip airplane o side plank clamshell y retest.

### R3. Valgo bilateral con diferencia bilateral ausente

**Disparador**

- ambas rodillas cumplen valgo;
- sus magnitudes son similares;
- diferencia bilateral ausente.

**Texto de usuario**

> Ambas rodillas se desplazaron hacia medial de forma similar. El resultado describe una trayectoria bilateral, no una asimetría marcada entre lados.

**Verificación**

- stance/toe-out;
- pie y calzado en ambos lados;
- dorsiflexión bilateral;
- profundidad y carga;
- dolor o fatiga.

**Recomendación**

Priorizar una modificación bilateral de técnica o base de apoyo antes de elegir un correctivo unilateral. No usar la diferencia bilateral como segunda evidencia independiente.

### R4. Diferencia bilateral presente con ambas rodillas laterales

**Disparador**

- `L < 0` y `R < 0`;
- valgo ausente;
- `D_abs` presente o no concluyente;
- una rodilla tiene mayor magnitud lateral.

**Ejemplo**

```text
L = -25.01
R = -15.80
```

**Texto de usuario**

> Ambas rodillas se abrieron hacia fuera. La izquierda quedó más abierta que la derecha. Esto representa una diferencia bilateral de apertura, no valgo.

**Clasificación semántica del sistema**

```text
relation_kind = lateral_predominance
predominant_side = izquierda
```

Este predominio lateral es distinto del predominio medial usado para describir valgo. El sistema debe conservar ambos conceptos por separado.

Si el delta confirma cambio desde el inicio:

> Durante el descenso, la rodilla izquierda se abrió más que la derecha.

**Relevancia posible**

- stance o toe-out asimétrico;
- estrategia voluntaria de “rodillas afuera”;
- una cadera aporta menos apertura/ER que la otra;
- la cadera contraria aporta menos IR;
- diferencia de tobillo o apoyo;
- yaw corporal o perspectiva.

**Verificación**

1. confirmar protocolo, stance y ángulo de pies;
2. comparar FABER/ER/abducción;
3. comparar IR de cadera;
4. knee-to-wall;
5. repetir con instrucciones neutrales, sin cue exagerado de “knees out”.

**Caso específico: izquierda abre más, derecha abre menos**

Si además hay shift a la derecha, Squat University propone diferenciar:

- cadera derecha que no abre suficiente;
- cadera izquierda que no aporta IR suficiente.

No se elige una ruta por la imagen; se comparan FABER/ER derecha e IR izquierda.

- Conor Harris: `7tbu0bJsVBA`, `3ohY8T3N4u8`, `-IS1ikKA5nk`.

### R5. Diferencia bilateral con direcciones opuestas

**Disparador**

- una rodilla se mueve medialmente y la otra lateralmente.

**Texto de usuario**

> Las rodillas siguieron direcciones distintas: la izquierda se desplazó hacia medial mientras la derecha se abrió hacia lateral.

**Lectura**

No resumirlo solo como “predominio izquierdo/derecho”. Revisar simultáneamente pelvis, tronco, stance, pies y calidad de cámara.

**Verificación**

- dirección del shift pélvico;
- dirección de inclinación del tronco;
- ángulo de ambos pies;
- FABER/IR lado a lado;
- ankle wall test.

### R6. Shift pélvico hacia un lado

**Disparador**

- desplazamiento pélvico sostenido en descenso, cerca del fondo o ascenso.

**Lectura común de ambos autores**

La dirección del shift no identifica automáticamente el lado “débil”. Puede reflejar que un lado acepta mejor flexión/carga y el cuerpo evita el otro.

**Squat University**

Para shift a la derecha, diferenciar al menos:

- derecha con FABER/ER/apertura limitada;
- izquierda con IR limitada;
- tobillo o estabilidad lateral como alternativas.

**Conor Harris**

Dentro de su modelo, el shift puede ser una búsqueda de espacio posterior/IR en el sticking point. Propone abrir espacio posterior del lado evitado y luego transferir el rango a squat/hinge pequeño.

**Verificación**

- FABER/ER derecha e izquierda;
- IR de cadera;
- hip flexion;
- knee-to-wall;
- single-leg bridge o control lateral si movilidad mejora pero el squat no.

**Opciones condicionadas**

- lado que no abre: kettlebell/half-kneeling weight shift;
- lado que no acepta posterior hip/flexion: elevated-foot supported posterior hip shift;
- IR limitada: movilización específica y luego split squat/lateral squat;
- movilidad restaurada sin transferencia: estabilidad unilateral y tempo squat.

**Retest**

- prueba de cadera elegida;
- sentadilla con mismo stance, velocidad y profundidad.

### R7. Shift pélvico y rodilla del mismo lado abre menos

**Disparador de ejemplo**

- pelvis se desplaza a la derecha;
- derecha queda menos lateral/abierta que izquierda;
- valgo puede estar ausente.

**Texto de usuario**

> La pelvis se desplazó hacia la derecha y la rodilla derecha se abrió menos que la izquierda. Esta combinación es compatible con una diferencia de apertura o aceptación de carga entre caderas, pero no permite decidir por sí sola qué movilidad falta.

**Ruta de test**

1. FABER/ER/abducción derecha;
2. IR izquierda;
3. tobillo derecho e izquierdo;
4. repetir el squat sin cue de abrir rodillas.

**Decisión**

- si FABER/ER derecha es menor: probar intervención de apertura derecha y retest;
- si FABER es similar pero IR izquierda es menor: probar intervención de IR izquierda y retest;
- si ambos son similares: revisar tobillo, pie, estabilidad, anatomía, cámara y estrategia aprendida.

### R8. Pelvis y tronco se desplazan hacia el mismo lado

**Disparador**

- shift pélvico e inclinación del tronco comparten dirección y fase.

**Lectura**

Puede representar una estrategia global del centro de masa. No atribuir automáticamente la inclinación a debilidad del core ni el shift a una sola cadera.

**Verificación**

- cámara nivelada y cuerpo sin yaw;
- brazos simétricos;
- movilidad de cadera y tobillo;
- dolor/protección;
- comparar goblet squat o apoyo externo.

**Opción práctica**

Un goblet squat con contrapeso, apoyo en mesa/TRX o talones elevados puede servir como retest para comprobar si una mejor organización del centro de masa reduce ambas señales.

**Fuentes**

- Conor Harris: `J0gBeidOxM0`, `vqzG0_W2ZUY`, `familia-squat-depth-butt-wink-heel-elevation`;
- Squat University: `familia-squat-tecnica-depth-butt-wink`, `my0tLDaWyDU`.

### R9. Tronco inclina sin shift pélvico

**Disparador**

- inclinación lateral presente;
- pelvis ausente;
- rodillas sin patrón concordante.

**Lectura**

Antes de inferir una restricción de cadera, revisar:

- brazos o carga asimétrica;
- posición de cámara;
- torso/fémur y estrategia de equilibrio;
- rotación corporal respecto a la cámara;
- fatiga o hábito técnico.

**Texto de usuario**

> Se observó inclinación lateral del tronco sin un desplazamiento pélvico concordante. Conviene verificar la grabación y la estrategia de equilibrio antes de relacionarlo con una limitación de cadera.

No ofrecer un correctivo pélvico automático.

### R10. Tronco contrarresta el shift de pelvis

**Disparador**

- pelvis se desplaza a un lado;
- tronco inclina al lado contrario durante el mismo intervalo.

**Lectura**

Puede ser una estrategia de contrapeso para conservar el centro de masa sobre la base. La combinación es más informativa que cada variable aislada, pero sigue necesitando tests de cadera/tobillo y control de cámara.

**Recomendación**

Mostrar ambas señales juntas y sugerir evaluación de hip shift. No emitir dos recomendaciones independientes que puedan contradecirse.

### R11. Compensación aparece cerca de paralelo/sticking point — deshabilitada

**Estado: `disabled_requires_sagittal_measurement`.**

Esta regla no participa en recomendaciones de la versión frontal actual. El rango de 60–100° corresponde a flexión de cadera en el plano sagital; no puede calcularse de forma válida desde la proyección frontal de MediaPipe. La profundidad vertical y el porcentaje del descenso pueden describir cuándo apareció una señal, pero no sustituyen esos grados ni activan R11.

**Disparador**

- shift, diferencia bilateral o valgo aparecen al final del descenso, cerca del fondo, pero no desde el inicio.

**Harris**

Dentro de su modelo, la región aproximada de 60–100° de flexión de cadera demanda acceso relativo a IR, pronación y dorsiflexión. Un shift puede funcionar como búsqueda de ese rango.

**Squat University**

Recomienda diferenciar anatomía/stance, cadera, tobillo, pie y estabilidad mediante tests y retest del squat.

**Texto de usuario**

> La diferencia apareció al aproximarse a la máxima profundidad, donde aumentan las demandas de cadera y tobillo. Esto orienta a revisar movilidad y control, pero no identifica por sí solo la estructura responsable.

**Verificación**

- hip IR en flexión;
- FABER/ER;
- knee-to-wall;
- stance/toe-out;
- talón elevado como retest, no como diagnóstico.

**Condición futura de habilitación**

- vista sagital estandarizada o sistema 3D validado;
- definición validada del ángulo de flexión de cadera;
- calibración de la relación entre ese ángulo, fase y resultado experto.

### R12. Talón elevado mejora el patrón — deshabilitada

**Estado: `disabled_requires_cross_video_protocol`.**

Esta regla no participa en comparaciones entre repeticiones de un mismo video. Requiere dos videos o condiciones registrados explícitamente —por ejemplo, sin elevación y con elevación— bajo un protocolo comparable. Se reserva para una extensión futura de comparación entre análisis.

**Lectura**

La mejoría puede relacionarse con menor demanda de dorsiflexión, mejor centro de masa o acceso más cómodo a profundidad. No confirma que el tobillo sea la única causa.

**Verificación**

- knee-to-wall;
- comparación de hip IR y stance;
- repetir sin elevar talones después de una intervención específica.

## 6. Priorización de tests sugeridos

El sistema no debe mostrar diez pruebas a la vez. Elegirá una o dos según la combinación:

| Combinación | Primer test | Segundo test |
| --- | --- | --- |
| shift D + derecha abre menos | FABER/ER D | IR I |
| shift I + izquierda abre menos | FABER/ER I | IR D |
| valgo unilateral sin shift | pie/trípode y tibial rotation | hip IR/control lateral |
| valgo bilateral | pie/tobillo bilateral | stance y hip mobility |
| diferencia lateral sin valgo | stance/toe-out | FABER/ER y luego IR |
| shift con rodillas simétricas | hip flexion/FABER/IR | ankle wall test |
| tronco + pelvis mismo lado | grabación/centro de masa | cadera/tobillo |
| tronco aislado | cámara/brazos | anatomía y equilibrio |
| patrón mejora con talón elevado | **R12 deshabilitada:** requiere comparación futura entre dos condiciones/videos | — |

## 8. Orden de selección de recomendación

```text
1. calidad insuficiente
   -> no recomendar; pedir nueva grabación

2. dolor/red flags declarados
   -> derivación o modificación conservadora

3. señal aislada
   -> descripción + test

4. combinación concordante
   -> descripción conjunta + test priorizado

5. test confirmado por el usuario/profesional
   -> drill específico + retest
```

Cuando existe una combinación, debe suprimirse la recomendación aislada redundante. Ejemplo: `shift derecho + derecha abre menos` genera una sola ruta integrada, no tres tarjetas separadas para pelvis, rodilla y asimetría.

## 9. Retest

Toda opción práctica debe pedir:

1. repetir el test que justificó la elección;
2. repetir la sentadilla con:
   - mismo stance;
   - mismo toe-out;
   - mismo calzado y soporte de talón;
   - misma profundidad objetivo;
   - velocidad comparable;
   - misma posición de cámara;
3. comparar:
   - magnitud;
   - fase de aparición;
   - duración;
   - comodidad/dolor informado.

Una mejoría inmediata indica utilidad provisional para esa tarea y ocasión; no demuestra corrección estructural permanente.

## 11. Criterios de aceptación de la capa de recomendaciones

- El caso “izquierda se abrió más que derecha” no recibe recomendación de valgo.
- El sistema menciona ambas rodillas en toda diferencia bilateral.
- Una diferencia bilateral medial, lateral u opuesta produce textos distintos.
- La fase modifica la explicación, no el umbral sin validación.
- Un pequeño movimiento medial solo en ascenso no se etiqueta automáticamente como dañino.
- Un shift genera primero tests de cadera/tobillo, no una causa cerrada.
- No se muestran ejercicios si el test diferencial todavía no se realizó.
- Las combinaciones suprimen recomendaciones redundantes por variable aislada.
- Cada recomendación conserva fuentes, retest, límites y red flags.
- Nunca se diagnostica Left AIC, PEC, lesión o debilidad muscular desde la sentadilla 2D.
