# Storyboard: de una señal ruidosa a una repetición válida

Duración: 18 segundos. Formato: 1920 × 1080.

1. **0–5 s — Limpieza.** Aparece una señal cruda con pequeñas oscilaciones y un hueco. La señal final se dibuja encima; el mensaje aclara que la calidad original no se modifica.
2. **5–11 s — Prominencia.** Se marca el pico, sus bases laterales y la distancia vertical. El umbral adaptativo aparece como regla de aceptación.
3. **11–18 s — Recuperación.** Dos máximos cercanos parecen dos repeticiones. Se mide el valle, se compara `0.000204 < 0.03` y ambos candidatos se fusionan en una sola ejecución.

La animación es una demostración conceptual controlada; la evidencia experimental permanece en la aplicación web y los artefactos del caso.
